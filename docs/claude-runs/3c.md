**Đã lần theo mọi đường tạo/thay match trong Run mode:**

| Đường | Có tạo/thay match không |
|---|---|
| `RunFlow.Fight` → `StartFight` → `Run.CreateMatch()` → `MatchPrepared` → `ArenaView.StartMatch(sim)` | Đường chuẩn, 1 lần mỗi trận |
| `RunFlow.Continue` (CONTINUE ở màn tiêu đề, run đang khoá) → `StartFight` | Chỉ từ màn tiêu đề |
| `ArenaView.StartMatch` khi đang step → `pending` | Chỉ khi gọi trong lúc step; Run mode không gọi ở đó |
| `ArenaView.AutoRestart` | `GameController.Awake` và scene đều đặt `false` |
| `ArenaView.Start()` khi `Sim == null` | Chỉ frame đầu của scene |
| Versus `MatchFlow.RoundPrepared` → `StartMatch(a, b, seed)` | Chỉ khi Versus đang chạy (menu Versus bị ẩn khi mở Run) |
| `PrepareView.Show` / `FightReport.Build` gọi `CreateMatch()` để xem trước | Tạo bản riêng, không đưa vào ArenaView |
| SKIP FREE PICK → YES | Gọi `FightRequested` một lần, giống FIGHT thường |
| Màn kết quả (`NextAfterResult`) | Chỉ đổi trạng thái sang Prepare/Summary |
