# BB-18 — BGLGXLQ orbs (Rules 16 → 17)

Asked by Phu on 16/10/2026: "5 quả bóng bay quanh, hít bóng khác ở gần màu nào sẽ thắp sáng màu đó và cho thêm buff tùy theo màu, đủ 5 màu thì phóng tuyệt chiêu".

Phu's answers:
- **Lights by:** an orb touching the enemy.
- **Order:** any order; an orb that is already lit does not count again.
- **Ultimate:** stays UNITY (the 5-colour burst).

## Rule
- **Orbs.** Five Sim orbs (PINK, GREEN, BLUE, YELLOW, RED) circle the ball.
  - Orbit distance: ball radius + `ChorusOrbGap` (9).
  - Orb radius: `ChorusOrbRadius` (4).
  - Turn speed: `ChorusOrbSpin`, 3°/tick.
- **Touch.** An unlit orb that touches an enemy body:
  - lights its colour;
  - deals `ChorusOrbDamage` (0.25, ability);
  - turns on that colour's gift.
  - At most one colour lights per `ChorusLightGapTicks` (60).
- **Gifts:**

  | Colour | Gift |
  |---|---|
  | PINK | heal per melee hit |
  | GREEN | top speed |
  | BLUE | 1 shield charge |
  | YELLOW | melee damage |
  | RED | burns the enemy it touched |

- **UNITY.** Lighting all five fires UNITY (unchanged burst).
  - The ring then goes dark for `ChorusDarkTicks` (90).
  - Each ring still adds melee damage for good.
- **Melee.** The halo blade still deals the melee hits, but no longer lights colours.
- **Event.** `ChorusLit`:
  - Value = the colour (1–5);
  - Variant = colours lit so far;
  - B = the enemy touched (-1 for HYMN or OPENER);
  - Point = the orb.
- **HYMN** lights the first two **unlit** colours ("LIGHT 2 UNLIT COLOURS").
- **Kept as before:** EVERLIGHT keeps PINK lit; MORNING LIGHT starts with PINK; DOUBLE RAINBOW.
- **View.** `TributeView` draws the orbs at the Sim positions: lit 10 px, unlit 7 px dimmed.

- **Seeds:** Versus uses 200 seeds per side against each ball. Run uses the BB-15 sweep: 18 ten-point trees, seeds 3001–3200.
- **Run is in range.** LV1 15.5% (better than 14.5%). Best LV10 build 68.5% (gate ≤ 70). Spread 47–68.5.
- **Versus is not.** The mean is 62.7%; it beats aegis 95.8%, venom 92.8%, blade 88.5%, and loses to brawler 11.3%.
  - The shape matches the old BGLGXLQ (it already lost to brawler 18% and beat aegis/venom 77%), only stronger.
  - Diagnostics (`ChorusRingsDiag`):
    - rings per minute went from about 4 to about 5.4;
    - against brawler it is a pure damage race (chorus deals ~80–100/min, takes ~148/min);
    - against aegis/venom, chorus wins on damage over time.
  - Grids over light gap, dark pause, orb damage, start damage, ring growth, UNITY and PINK heal (`ChorusOrbReport.OrbTuningGrid`) never brought both ends into 20–80 together: lowering the power drops brawler toward 0% first.
- **Decision for Phu:**
  - (a) a Versus-only lever (the Run keeps pass 1); or
  - (b) accept the matchup spread; or
  - (c) let the orbs also absorb projectiles, to help against VOLLEY and RIG.
