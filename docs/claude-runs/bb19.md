# BB-19: tap-triggered (active) skills in Run

Phu (17/10): the Run player taps to use the skill, with a cooldown like the current strike bar.

## What changed (Sim only, Rules 18 -> 19)
- `SkillState`: when the ball has a `TapState` (Run player) the skill is **manual**: no auto-fire, `IsReady`/`ReadyFraction`/`TryFire()`; cooldown = `TapTuning.ManualCooldownPercent` (200%) of the old automatic cooldown (about 20-24 s), starts half charged. Enemies and Versus keep auto skills.
- `TapState`: in skill mode the tap fires the skill (`TryFire`) and the cooldown bar shows the skill's charge; otherwise the old strike.
- Active versions for fang (spin up), brawler (dash at nearest foe), venom (poison stacks on nearest foe), rig (turret + overclock); other weapons fire their normal effect on tap.
- `MatchSim` attaches the skill to the tap after creating `TapState`.
- Tests: `RunBot.TapIfReady` (bots tap), `ActCooldownGrid` (explicit grid), goldens re-pinned (masked digests unchanged, old values kept in comment).
